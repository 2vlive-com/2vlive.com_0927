# มองบวกไว้ก่อน! "แฮร์รี่ เคน" เชื่ออังกฤษสู้กับสเปนได้สูสี แม้สุดท้ายพ่าย 2-3
แฮร์รี่ เคน กองหน้ากัปตันทีมชาติอังกฤษ เชื่อทัพ "สิงโตคำราม" สามารถมองในแง่บวกจากเกมที่พวกเขาแพ้ สเปน 2-3 ที่สนามเวมบลีย์ ในศึกยูฟ่า เนชั่นส์ ลีก ลีกเอ กลุ่ม 3 เมื่อวันเสาร์ที่ 26 กันยายนที่ผ่านมา
ดาวยิง บาเยิร์น มิวนิค มองว่า อังกฤษ สู้กับทีมแชมป์ฟุตบอลโลก 2026 ได้ดี และเชื่อว่าหากเป็นวันอื่น ผลการแข่งขันอาจออกมาแตกต่างจากนี้ นอกจากนี้เขายังเปรียบเทียบฟอร์มการเล่นในแมตช์นี้กับผลงานของ "ทรี ไลอ้อนส์" ในศึกฟุตบอลโลกครั้งล่าสุด ซึ่งพวกเขาเล่นได้อย่างแข็งแกร่ง  แต่ประสบปัญหาในการรักษามาตรฐานการเล่นให้อยู่ในระดับเดิมตลอด 90 นาที
 เคน ซึ่งโหม่งบอลไปแฉลบตัว มาร์ก กูกูเรย่า เข้าประตูช่วยให้ อังกฤษ นำ 2-1 ในครึ่งแรก แต่ดันพลาดจุดโทษในครึ่งหลัง เปิดใจว่า "ก่อนหน้านี้ผมเคยพูดว่า ในฟุตบอลโลก เราเคยเล่นได้ถึงระดับที่ดีมาก แต่ยังไม่สามารถรักษาฟอร์มการเล่นที่ยอดเยี่ยมได้ตลอด 90 นาที และวันนี้ก็คงคล้ายๆ กัน"
"เรามีช่วงเวลาที่เล่นได้ดีอยู่สองสามช่วง  และนั่นคือมาตรฐานที่เรารู้ว่าเราสามารถไปถึงได้ เรากำลังสู้กับทีมแชมป์โลกและแชมป์ยุโรป และเราสู้กับพวกเขาได้แบบสูสี หากเป็นวันอื่น แน่นอนว่าเราอาจเป็นฝ่ายคว้าชัยชนะในเกมนี้ได้ เราต้องมองถึงแง่บวกจากเกมนี้ เราต้องลุกขึ้นมาแล้วกลับมาลุยกันใหม่ในอีกไม่กี่วันข้างหน้า" เคน ระบุ
